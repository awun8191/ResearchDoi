# ResearchDoi

ResearchDoi is a platform for searching, retrieving, and managing academic research papers and their DOIs.

## Architecture

This repository contains three main components:

- **API** — FastAPI backend service for research paper management
- **ResearchDoi** — React frontend application
- **AGENT** — AI-powered agent system for research assistance

## Quick Start

1. Clone the repository
2. Copy `.env.example` files to `.env` in each component directory
3. Fill in the required API keys
4. Follow the README in each component for specific setup instructions

## Components

- `API/` - Backend API service
- `ResearchDoi/` - Frontend web application
- `AGENT/` - AI agent system
- `docs/` - Documentation and specifications
- `design-system/` - Design system assets
